# Security Policy

## Supported Versions

We actively provide security updates for the following release branches:

| Version | Supported |
| :--- | :--- |
| **Release v1.x** | :white_check_mark: Yes |
| **Release v0.x** | :warning: Critical Bugs Only |

---

## Reporting a Vulnerability

We take the security of our platform seriously. If you identify a security vulnerability within the Google Search Quality Platform, please do **not** file a public GitHub issue. Instead, report it through the private channels detailed below.

### Disclosure Process
1. **Send Report**: Email your report to **security@search-quality-platform.org**.
2. **Details to Include**:
   * A detailed description of the vulnerability.
   * Steps to reproduce the exploit (scripts, inputs, or configurations).
   * Potential impact (e.g. SQL Injection, memory exhaustion, credential leaks).
3. **Response Timeline**:
   * Maintainers will acknowledge receipt of your report within 48 hours.
   * We aim to provide a detailed response and mitigation plan within 7 days.
   * We request that you keep the vulnerability confidential until we have released a patch and published the advisory.

Thank you for helping keep our platform secure!
